## Risk & Assumption Log
**RISK-20261119-V10-01 — Beta label interpreted as production/safety certification**  
Mitigation: explicit Pilot/Beta Boundary and tester acknowledgement.

**RISK-20261119-V10-02 — Monitoring becomes hidden user telemetry**  
Mitigation: monitor checks only public Pages/system data; documented and testable.

**RISK-20261119-V10-03 — Public bug report leaks personal locations**  
Mitigation: issue form contains explicit privacy warning and required privacy acknowledgement.

**RISK-20261119-V10-04 — Tester pack contains optional free-text feedback**  
Mitigation: export is user-initiated and UI instructs user to review before sharing.

**RISK-20261119-V10-05 — Local analytics opt-out is cosmetic**  
Mitigation: `track()` exits before local storage/remote send when disabled; regression-tested.
