## Business Learning Log

**BL-20261119-01**  
Context: XPLORE had route generation, navigation, transit and decision intelligence but no durable mechanism to learn whether recommendations were useful.  
Change: Added a journey feedback and product-learning loop.  
Rationale: Feature growth without behavioural evidence would make prioritisation increasingly speculative.  
Evidence: Existing product roadmap identified feedback + analytics as the next P0 step.  
Expected learning: route usefulness, wrong-destination frequency, ETA complaints, mode-specific quality problems and recommendation preference versus fastest route.

## System Log

**SYS-20261119-01**  
Change: Added `learning-core.js`, `learning-v06.js` and `learning-v06.css`.  
Integration point: loaded after navigation recovery and Cork place-search modules so v0.6 can observe the final composed journey flow without changing routing providers.  
Failure boundary: learning-storage or collector failure must not stop routing/navigation.

## Architecture Log

**ARCH-20261119-01**  
Decision: keep v0.6 as a client-side learning adapter rather than introducing an ungoverned analytics SaaS dependency.  
Components:
- privacy/sanitisation core
- local event journal
- local feedback journal
- optional future collector interface
- export/clear controls
- UI feedback surface
Rationale: preserve location privacy while creating a measurable beta funnel.

## Recommendation Log

**REC-20261119-01**  
Recommendation: do not configure remote analytics until XPLORE owns a governed backend endpoint with validation, rate limiting, privacy controls and no privileged browser credentials.  
Status: ACCEPTED IN v0.6 DESIGN.

## Experiment Log

**EXP-20261119-01**  
Experiment: 30-day coarse funnel as the first product-learning model.  
Funnel: Search -> Results -> Guidance -> Arrival -> Feedback.  
Success criteria for beta: sufficient events to identify major drop-off and route-quality complaint categories without storing location history.

## External Evidence Log

**EXT-20261119-01**

v0.6 uses browser storage and existing XPLORE runtime state only.  
Implication: no new analytics vendor, cookie SDK or third-party tracker was introduced.

## Risk & Assumption Log

**RISK-20261119-01 — Sensitive location leakage**  
Likelihood: Medium without controls.  
Impact: High.  
Mitigation: deny-list sanitizer, coarse buckets, no raw coordinates/addresses/Eircodes/names in analytics events, automated tests.  
Status: MITIGATED / CONTINUE REVIEW.

**RISK-20261119-02 — Local-only analytics fragmentation**  
Likelihood: High.  
Impact: Medium.  
Mitigation: user-initiated export now; governed collector contract reserved for later backend.  
Status: ACCEPTED FOR v0.6 BETA.

**RISK-20261119-03 — Feedback bias**  
Likelihood: High.  
Impact: Medium.  
Mitigation: treat feedback as product evidence, not objective safety/accessibility truth; compare with routing/context evidence.  
Status: ACTIVE.

**RISK-20261119-04 — Mobile prompt obstruction**  
Likelihood: Medium.  
Impact: Medium.  
Mitigation: card stays collapsed during normal use and prompts only after arrival or a meaningful guidance session.  
Status: REAL-DEVICE VALIDATION REQUIRED.

## Decision Log

**DEC-20261119-01**  
Decision: v0.6 = Learn.  
Scope: feedback + product analytics + route-quality reporting.  
Out of scope: NTA realtime, route-intelligence score integration, native background GPS.

**DEC-20261119-02**  
Decision: analytics is local-only by default.  
Reason: static GitHub Pages cannot safely hold privileged ingestion credentials.

**DEC-20261119-03**  
Decision: free-text notes are never included in anonymous shared payloads.

## Security & Privacy Log

**SEC-20261119-01**  
Control: analytics sanitizer blocks latitude, longitude, address, Eircode, query, coordinates, origin/destination identifiers, names, notes and messages by key pattern.

**SEC-20261119-02**  
Control: remote sharing is disabled when no XPLORE collector endpoint is configured and remains opt-in if one is later supplied.
