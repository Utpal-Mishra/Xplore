# XPLORE Product / Feature Log

## 2026-11-19 — PF-LOC-001 — Nearest relevant place
**User problem:** Searching a chain such as “Circle K” from Kildare could return a Cork location.

**Feature behavior:** XPLORE now selects the nearest relevant matching branch relative to the journey start/live location and displays the selected place plus its approximate distance from the anchor.

**UX change:** Cork-specific default origin/destination values were removed.
