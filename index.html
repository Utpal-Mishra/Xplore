Pilot Boundary

XPLORE v0.4.6 introduces dynamic Ireland address autocomplete: Start and Destination suggestions appear while typing using a debounced Photon/OpenStreetMap development adapter, obsolete requests are cancelled, results are biased toward an already-known current/start location, and keyboard selection is supported. Ordinary fuzzy results still require explicit user selection before routing, while exact Eircodes retain their dedicated fail-safe resolver. Route Intelligence remains sampled and is not yet included in the XPLORE Score while validation continues.
